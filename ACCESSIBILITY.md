# Accessibility

Ecological Intentionality is intended to be readable, navigable, and reusable by as many people as reasonably possible.

## Current commitments

The project aims to:

- use semantic Markdown wherever possible;
- keep headings hierarchical and descriptive;
- use meaningful link text;
- avoid relying on color alone to communicate meaning;
- keep tables relatively simple;
- provide text equivalents when visual material is essential to understanding the research;
- preserve readable plain-text source files in the repository.

## Known limitations

Some exported materials may originate in a visual research environment and may not yet have complete accessibility descriptions.

GitHub rendering, linked websites, and third-party services also have accessibility characteristics outside this repository's direct control.

## Reporting a barrier

If you encounter an accessibility barrier in the repository, public field notes, documentation, or related project materials, please open an issue or contact:
